## Things I've Built

### Networked Space Simulation

I'm currently building a large-scale Unreal Engine project with a focus on networking and space simulation.

I've worked on a **C++17 network stack over UDP** capable of transporting generalized data and supporting SCTP-like data flows.

On the simulation side, I've implemented a **six-degree-of-freedom Newtonian spacecraft flight model**, including force accumulation, velocity integration, rotational motion, and coordinate-frame transformations, where I play around with explicit Euler, Verlet, and RK4 integrations.

### 3D Game Engine

With the SFSU Game Development Club, I worked with a team building a **3D game engine using an Entity Component System and Vulkan**.

### Embedded Systems

For an embedded systems project, I helped build an autonomous miniature car around a **Raspberry Pi Zero 2 W**.

The software was written in **C**, including our own libraries and direct register access.

I'm particularly interested in the boundary between software and hardware — where understanding the machine underneath actually matters.

### Game Development

I enjoy making games as much as I enjoy building the technology behind them.

I've worked on projects ranging from game-jam experiments to a 3D rocket game and larger Unreal Engine projects.
